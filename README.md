# Jetiev_learningAI

> A personal journey of learning Artificial Intelligence — from Machine Learning fundamentals to Deep Learning, LLMs, and AI Systems.

## About This Repository

This repository documents my journey of learning AI from the ground up.

My goal is not only to learn how to use existing AI libraries and frameworks, but to understand the fundamental ideas behind AI systems:

* How machine learning algorithms work
* How models learn from data
* How optimization works
* How neural networks learn representations
* How modern LLMs are trained and used
* How AI systems are built and deployed in real-world applications

I use this repository to document what I learn, implement algorithms from scratch, run experiments, and build practical projects.
